# 微信小程序本机预览

已提供四个微信原生页面：排盘、命盘、AI 解读、历史。排盘和历史在本机运行，不依赖 Vercel，不需要 OpenAI Key。已在微信开发者工具 Stable 2.02.2608080 的 iPhone 12/13 (Pro) 模拟器实际编译运行，随后改用工具提供的测试号生成手机预览码；用户扫码反馈已能打开并排盘。智谱 AI 已在本机及公网接口实测成功，微信端仍被合法请求域名检查拦截，手机 AI 尚未通过，未上传发布。

## 如何打开

1. 从[微信开发者工具官方页](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)下载适合 Apple 芯片 Mac 的版本。本机是 arm64；安装包与系统要求以官网为准。
2. 当前已导入桌面 `/Users/mac/Desktop/紫微观星-小程序预览`，工具中的项目名为“紫微·观星”。也可导入仓库的 `miniprogram/` 目录；不要选择上层 Next.js 仓库。
3. 工具启动页选择“游客模式”，导入时 AppID 自动为 `touristappid`，后端服务选择“不使用云服务”。已实测当前版本可这样完成本机导入；`touristappid` 不是真实 AppID。
4. 点击“编译”，查看电脑模拟器中的四个标签。

游客项目的“预览”（手机二维码）、“真机调试”和“上传”菜单为禁用状态。手机预览需切换为工具提供的测试号，操作见下一节；仓库保留通用的 `touristappid`，没有提交本人的测试 AppID。

目录已包含编译好的 `utils/chart-engine.js`。首次导入无需在工具里“构建 npm”，也无需在 `miniprogram` 中安装 npm 包。包内包含完整第三方许可通知，不包含 API Key。

## 手机微信预览

1. 登录微信开发者工具，选择“项目 → 新建项目”，在创建小程序页面点击 AppID 旁的“测试号”。使用工具实际提供的 AppID，不要自行编造；记下后可取消空白项目的创建。
2. 回到已导入的“紫微·观星”，打开右上角“详情 → 基本信息”，修改 AppID 为自己的测试号，继续选择“不使用云服务”。切换 AppID 后本机历史使用新的存储空间，原游客历史不会自动迁移。
3. 重新编译，点击“预览”。如果出现多端框架介绍，选择“继续预览小程序”。等待打包和二维码生成，再用手机微信扫描；二维码过期后重新点击预览。
4. 当前桌面副本已经配置测试号，无需重复修改。不要用仓库的游客配置覆盖它，也不要把个人测试号和预览二维码提交到公开仓库。

首次预览包约 852 KB，官方工具成功生成二维码。2026-10-24 用户反馈“已打开并能排盘”，同时反馈 AI 不能解读；当时尚未配置后端。此后已接入智谱及本机临时通道，最新状态见下节和验证记录。此次只确认手机打开及排盘；没有据此声称手机全部功能已验收。测试号启用了预览和真机调试入口，上传仍禁用，不能据此直接正式发布。

## 试用顺序

- 在“排盘”修改默认示例的公历日期、时辰、性别，点击“开始排盘”。晚子时 23:00–23:59 按次日排盘，闰月分前后半月，流年在农历正月初一换年。
- 在“命盘”查看十二宫、主辅星和四化；切换本命、大限、流年，点击宫位查看全部星曜。
- 点击“保存命盘到本机”，到“历史”重新载入或确认删除。最多保留 20 张；不同于 Safari 网页历史，不自动跨设备同步。
- “AI 解读”默认显示尚未连接服务，不生成虚假的解读。

## AI 后端配置

当前选择[电脑运行后端和临时 HTTPS 通道](LOCAL_AI_PREVIEW.md)。用户曾明确同意出生信息、AI 访问口令与解读结果经 Cloudflare 转发，公网真实解读已成功；微信开发工具因临时域名未在合法列表而拦截。用户选择保持校验，等待注册正式小程序账号，因此本次通道和本机 API 已关闭，桌面副本的失效地址已清空。手机 AI 尚未通过。

当前按用户要求不使用 Vercel；本机及公网 API 已用合成示例通过真实智谱五项解读。要启用 AI，先按[本机预览说明](LOCAL_AI_PREVIEW.md)启动后端，或按[部署说明](MOBILE_DEPLOY.md)部署本仓库后端，国内方案在服务端设置 `AI_PROVIDER=zhipu`、`ZHIPU_API_KEY`、`AI_ACCESS_TOKEN`，`ZHIPU_MODEL` 仅允许当前免费定价的 `glm-4.7-flash` / `glm-4-flash-250414`，本机已验证后者。然后在 `miniprogram/config.js` 的 `apiBaseUrl` 填公开 HTTPS 服务端地址，保持 `aiProvider: 'zhipu'` 与服务端一致。免费模型仍需注册并创建智谱标准 API Key，不自动切换到付费模型。

**不要将任何模型 API Key 写入小程序源码、配置或请求参数。** 页面中的访问口令是部署者提供的测试口令，只保留在当前页面内存，离页清空。用户明确同意后，小程序将出生信息发送给后端重新排盘；后端把必要的命盘结构发送给页面显示的服务商（当前国内方案为智谱 BigModel）。历史不保存 AI 回答或口令。

使用真实 AppID 时，还需要在官方后台配置合法请求域名，分别验证手机网络与 API 访问。不要用关闭域名或证书校验的方式替代正式配置。

## 开发与验证

在仓库根目录执行：

```bash
npm ci
npm run build:miniprogram
npm run test:miniprogram
npm run typecheck
```

`test:miniprogram` 会重新打包，再运行 `tests/miniprogram*.test.ts`。当前 20 项通过，覆盖无 Intl / Node / 浏览器全局变量的引擎执行、与网页版排盘结果比对、晚子跨年、四化、大限流年、历史损坏保护，以及模拟的 AI 成功、超时与旧响应隔离。没有真实调用 OpenAI。

引擎采用 CommonJS 独立包，无外部模块依赖，当前约 853 KiB。领域源码位于 `miniprogram/src/engine.ts` 和共享 `lib/`，修改后须重新打包。开发者工具的 `project.private.config.json` 已加入 Git 忽略。
